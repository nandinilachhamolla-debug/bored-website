# Bored Website

## About
The Bored Website helps users find interesting activities whenever they feel bored. It provides random activity suggestions to make free time enjoyable.

## Features
- Random activity suggestions
- Simple and user-friendly interface
- Responsive design
- Easy to use

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open the `index.html` file in your web browser.

- Add activity categories
